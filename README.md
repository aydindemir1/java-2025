# Java Backend Development

Java backend development çalışmalarını içeren, temel Java konularından Spring Boot tabanlı REST API geliştirme ve test süreçlerine kadar ilerleyen uygulamalı öğrenme repository'sidir.

Repository; Java, OOP, Collections, Streams, Exception Handling, Concurrency, SQL/RDBMS, JPA/Hibernate, Spring Boot, REST API, MongoDB, Docker ve Spring Boot Testing konularında örnek projeler içermektedir.
