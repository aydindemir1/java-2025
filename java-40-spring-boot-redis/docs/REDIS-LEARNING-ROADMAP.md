# Redis Learning Roadmap
1. Temel: StringRedisTemplate, SET/GET, EXISTS, DELETE, TTL, EXPIRE, INCR, DECR.
2. Veri Yapıları: Hash, List, Set, Sorted Set.
3. Cache: cache-aside, annotations, invalidation, TTL, serialization.
4. Gerçek Senaryolar: session, counter, leaderboard, recent-items, unique-users.
5. Messaging: Pub/Sub ile geçici yayın; Streams ile kalıcı event log yaklaşımı.
6. Concurrency: transactions, WATCH optimistic locking, distributed lock.
7. Production: rate limiting, idempotency, SCAN, pooling, eviction, stampede, hot key ve graceful fallback.
