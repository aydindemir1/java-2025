# Java 39 - Spring Boot Logging

Bu proje, Spring Boot uygulamalarında temel logging kullanımını öğrenmek ve uygulamak amacıyla geliştirilmiştir.

Projede SLF4J ve Spring Boot'un varsayılan logging altyapısı kullanılarak farklı log seviyeleri, console logging, file logging ve exception logging örnekleri uygulanmıştır.

## Kullanılan Teknolojiler

- Java 21
- Spring Boot 4.1.1
- Spring Web
- Spring Boot Actuator
- SLF4J
- Logback
- Springdoc OpenAPI / Swagger UI
- Maven
